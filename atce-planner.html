How the session types work

Technical sessions
Numbered 01, 02… in the program. Each is a 3-hour block in one room with a run of papers back to back, typically about 25 minutes each (session pages show slots like 08:30–08:55). Coming and going between papers is normal. Check the paper times on the session page or the SPE app and walk in for the talk you want. Paper-level times were not in the program text, so I could not list them here.
Running at once
Ten technical sessions run in parallel in the Wednesday 14:00 block, so most choices are about which room to start in. Rooms 370 CF and 370 ADBE sit in the same numbered area, which likely makes hopping between them easy.
Special sessions (SS)
One hour, panel format with moderator and discussion. Stay for the whole hour. They run in pairs, SS rooms 1 and 2.
Strategic panels (SP)
One hour, all in Room 372 BCEF, usually with senior leaders. Yours is one of these.
ePosters
Short 30-minute poster slots at the breaks, at ePoster stations in Hall B.
